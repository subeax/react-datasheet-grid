# subeax maintained distribution

Based on upstream `nick-keller/react-datasheet-grid` 4.11.6 (commit
`862a1bb`). The npm package name remains `react-datasheet-grid`; install the
built release tarball, not the repository source archive.

## Selected changes

- [PR #385](https://github.com/nick-keller/react-datasheet-grid/pull/385):
  react-resize-detector 12.3+, removing the React 19-incompatible findDOMNode
  dependency. Supported peers are React 18 and 19.
- [PR #377](https://github.com/nick-keller/react-datasheet-grid/pull/377):
  **only** the scoped React JSX declaration fix, adapted to `React.JSX.Element`.
  No unrelated copy-with-headers, theme or test rewrites were adopted.
- [PR #368](https://github.com/nick-keller/react-datasheet-grid/pull/368):
  prefer plain-text clipboard values to HTML when both are supplied. This is
  intentional for numeric spreadsheets; HTML-only input remains supported.
  Both keyboard and context-menu paste paths are updated.
- Local fix: lazy text columns must have gained focus before committing on
  blur. StrictMode mount replay must not write rounded display values back.
  Reset change tracking on each focus session.
- CI uses Node 22 instead of the obsolete Node 12 workflow (same intent as
  [PR #384](https://github.com/nick-keller/react-datasheet-grid/pull/384)).

Not adopted: #349 adds a null fallback after `String.replace`, which cannot
fix undefined input and has no effect on strings. #327/#386 (sticky columns)
and #350 (resizing) are larger changes to selection/virtualization and need
separate behavioral testing before release. Existing frozen gutter is retained.

## Build and publish

```
npm ci --ignore-scripts
npm run build
npm test -- --runInBand
npm pack
```

Upload the resulting `react-datasheet-grid-<version>.tgz` to a matching GitHub
release. Consumers should pin the exact release URL and commit their lockfile
with tarball integrity. Never replace a published asset: issue a new version.
`dist` is generated by the build and included in the tarball; consumers do not
need build scripts, private registries or GitHub credentials.

The upstream Jest suite and regression tests run with React 18. React 19 runtime
and clipboard behavior are additionally exercised by the consuming application's
browser tests. Do not interpret this as adopting every change in the linked PRs.
