# subeax maintained distribution

Based on upstream `nick-keller/react-datasheet-grid` 4.11.6 (commit
`862a1bb`). The npm package name remains `react-datasheet-grid`; install the
built release tarball, not the repository source archive.

## Selected changes

- [PR #385](https://github.com/nick-keller/react-datasheet-grid/pull/385):
  react-resize-detector 12.3+, removing the React 19-incompatible findDOMNode
  dependency. Supported peers are React 18 and 19.
- [PR #377](https://github.com/nick-keller/react-datasheet-grid/pull/377):
  **only** the scoped React JSX declaration fix, adapted to `React.JSX.Element`.
  No unrelated copy-with-headers, theme or test rewrites were adopted.
- [PR #368](https://github.com/nick-keller/react-datasheet-grid/pull/368):
  prefer plain-text clipboard values to HTML when both are supplied. This is
  intentional for numeric spreadsheets; HTML-only input remains supported.
  Both keyboard and context-menu paste paths are updated.
- Local fix: lazy text columns must have gained focus before committing on
  blur. StrictMode mount replay must not write rounded display values back.
  Reset change tracking on each focus session.
- CI uses Node 22 instead of the obsolete Node 12 workflow (same intent as
  [PR #384](https://github.com/nick-keller/react-datasheet-grid/pull/384)).

- [PR #386](https://github.com/nick-keller/react-datasheet-grid/pull/386)
  (`bc1c29f8a91613026340f4c053fbc8e510a61086`, adapted): optional
  `stickyLeftColumnNumber` freezes the first N data columns after the gutter.
  The port also corrects gutter hit testing, frozen-column virtual ordering,
  same-row CSS layout, keyboard scrolling, drag selection and selection/fill
  overlays across the frozen boundary. The numeric prop remains dynamic in
  both grid variants, matching the existing primitive-prop contract. No default
  behavior changes: zero columns are frozen unless the consumer opts in.

Not adopted: #349 adds a null fallback after `String.replace`, which cannot
fix undefined input and has no effect on strings. #327's single-column variant
is superseded by #386's N-column API. #350 (resizing) remains a separate feature.
The existing frozen gutter and optional sticky-right column are retained.

## Build and publish

```
npm ci --ignore-scripts
npm run build
npm test -- --runInBand
npm pack
```

Upload the resulting `react-datasheet-grid-<version>.tgz` to a matching GitHub
release. Consumers should pin the exact release URL and commit their lockfile
with tarball integrity. Never replace a published asset: issue a new version.
`dist` is generated by the build and included in the tarball; consumers do not
need build scripts, private registries or GitHub credentials.

The upstream Jest suite and regression tests run with React 18. Browser tests
in `browser-tests/` exercise real horizontal/vertical layout, gutter selection,
editing/Escape, cross-pane clipboard and deletion, fill, keyboard scrolling,
and hidden-gutter/sticky-right combinations. Run them with:

```sh
npm exec playwright install chromium
npm run test:browser
BROWSER_TEST_MODE=production npm run test:browser
```

No screenshots, video or traces are recorded. The fixture is synthetic and does
not contain consuming-application code or data. To check another installed React
version without changing this package's dependency tree, set `REACT_TEST_ROOT`
to the project directory containing that version's `node_modules` (for example,
a temporary project with React 19 and React DOM 19 installed). CI checks both
React 18 and 19. These tooling dependencies are development-only; the runtime
dependency list is unchanged.

Do not interpret this as adopting every change in the linked PRs.
